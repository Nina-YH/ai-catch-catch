# 看法混合策略

> 占位说明：本文档后续填写「何时抓真实评论、何时 LLM 补足」的判定规则与态度判定标准。当前只写策略骨架，不含实现。

## 大众态度（正面 / 中立 / 负面 + 一句话理由）

- 有可抓评论的源（如 Hacker News，经 HN 官方 Algolia API）：
  - 抓取该条目的真实评论，提炼整体情绪倾向与代表性理由。
- 无评论可抓的源：
  - 由 LLM 综合标题与摘要，推断大众可能的态度（正/中/负 + 一句话理由）。

## 专家视角（一句话评价）

- 统一由 LLM 生成：从技术价值、产业影响、风险等角度给出一句话专业评价。

## 态度判定标准（待细化）

- 正面 / 中立 / 负面 的判定边界与示例。
- 理由的措辞规范（一句话、客观、可读）。
